## 用户决定

2026-09-06：将“开启Agent”放到左上角实际 AI 来源旁，默认关闭，解决简单问题进入多步研究的问题。
本决定取代 M5–M23 的默认开启口径；M23c 暖橙品牌、原侧栏、首页交流框与五分类紧凑布局保留。

## 行为与边界

- 左上角与设置页共用一个开关。未连接时不可开启；关闭时首页显示“普通对话 · Agent 已关闭”。
- 旧平铺/v2 自动开启配置按关闭读取，不在读取时修改密钥存储；明确切换写入偏好标记，刷新后保留。
  新来源默认关闭，同一来源重新测试/保存保留明确选择。
- 关闭时仍用选定来源：已验证 API 使用独立直连；Codex/Claude/WorkBuddy 订阅及其他 Responses 来源
  进入无工具、非持久会话的单轮内核，不创建聊天研究 MCP bridge，不运行研究工具循环，超时 120 秒。
  不转换订阅凭据、不伪造 API 直连能力、不使用后台默认来源兜底。标题翻译沿用同一来源的无工具通道。
- 开启时保留 M22 联网、数据、计算和任务工具。六阶段研究、辩论、Agent 回测及资料转写仍要求开启。
- 模式切换会取消在途聊天和前置订阅检查；取消不误报登录/连接失败，已开始的独立研究任务不随开关停止。
- 普通对话不联网，不声称获取了最新数据；问题需要实时证据时提示开启 Agent。保留资料引用与产出检查。
- 兼容边界：浏览器所有请求显式发送模式，缺少浏览器配置不借后台 AI；旧 CLI/API 未传 executionMode
  的兼容契约仍默认为 agent，本次没有迁移第三方 API 调用方。不要混同为浏览器默认开启。
