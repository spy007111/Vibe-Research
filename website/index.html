首页先看指数、自选和持仓，往下才是对话。左侧 8 个一级栏目；其他栏目右上角也能打开对话，围绕当前页面继续聊。

01 / HOME

首页

大盘与全球指数、自选、持仓盈亏一屏看完，开盘时价格自动刷新；隐私模式遮住金额。

02 / MARKET

每日复盘

涨跌面、量能、短线情绪、两融、行业资金和龙虎榜，打开就看市场处在什么状态。

03 / INTEL

产业资讯

资讯雷达找需要核对的新闻、公告和事件；产业信号看 GPU 租金、月度产业数据、原材料与招聘。

04 / SECTORS

产业研究

20 个产业板块，每个配一组分步研究提示词，由你的 AI 查资料梳理技术路线、产业链和格局。

05 / RESEARCH

个股深挖

A 股、港股、美股：K 线、财报前瞻与复盘、事件回看；六阶段研究生成带证据的报告。

06 / TOOLS

回测与候选池

用对话描述想法跑历史回测，和指数对照；候选池按你设的条件逐只核对。多空辩论目前只做 A 股。

07 / PORTFOLIO

我的股票

自选与持仓按交易流水记账，持仓体检、事件日历和收盘提醒；不能下单交易。

08 / LIBRARY

资料库

研报 PDF、Word 等本地归档，回答里的引用能回查原文；研究、回测与辩论报告可搜索回看。

Home first

打开先看自己的股票

指数、自选、持仓盈亏在最上面，再往下才是对话。合计按人民币、港元、美元分开，不换汇相加；没取到的显示「—」，不当成 0。

Local Knowledge

研报进入本地资料库

原文件不上传；只把与问题命中的正文片段交给所选模型，回答里的引用能回查原文。

Backtest

从一句不完整的假设开始

用对话描述想法；缺条件会继续追问，齐了再用历史数据跑。结果和指数对照，出累计收益、回撤、月度、年度 4 张图，存进研究记录。

03 · Connect once

先连接 AI。
之后全站共用。

第一次打开首页会弹出「请接入AI」：已登录的订阅点一下就能测试并保存，「其他接入方式」进入设置页填 API。测试成功才生效，失败不会覆盖当前配置；也可以先关掉弹窗浏览栏目。

订阅接入 No API key

自动检测本机 Claude Code、Codex 或 WorkBuddy 的安装与登录状态，使用对应订阅额度，不用往页面里填 key。研究阶段只开放产品的 5 个受控工具；Codex 需用 ChatGPT 账号登录。

API 接入 Bring your own

选供应商，填 API 地址、模型名和 key，要支持 Chat Completions 和工具调用；测试成功后保存，全站共用这一份来源。

不用切换模式 One source

对话、研究、辩论和回测用同一个来源，AI 按问题需要联网、取数和计算。条件不满足直接报错，不会悄悄换成别家。

本地隐私 Local first

key 持久保存在当前浏览器的本机配置，不是系统钥匙串；请求经本机后端转发，不进入仓库、后端配置与日志。共享电脑用完应主动清除。

04 · Evidence before confidence

把“会回答”升级成“可复核”。

每轮深度研究都会留下报告、证据、计算、冲突与运行清单。拿不到关键数据时，状态会明确变成 incomplete 或 failed，不用旧值或猜测填空。

  • 本地运行，用户数据不进入开源仓库
  • 资料数字保留来源、资料期与证据 id
  • 派生数字保留输入、函数与计算过程
  • 不推荐个股，不预测涨跌，不给买卖时机
  • 多空辩论目前只做 A 股
  • 研报只在本机归档，引用能回查原文
